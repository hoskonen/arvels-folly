# Arvel's Folly

A Skyrim Special Edition / Anniversary Edition mod that reworks the Golden Claw quest in Bleak Falls Barrow.

In vanilla, Arvel the Swift has the Golden Claw and you have to cut him out of the spider web to get it. In this mod, the claw has fallen through the floor grate in the spider chamber, and you recover it with **Telekinesis**. Freeing Arvel becomes optional.

## Status

Work in progress. Not yet tested in game, so don't use it on a save you care about.

## Requirements

- Skyrim SE/AE
- No SKSE needed

## Installation

Install with a mod manager (Mod Organizer 2 or Vortex), or copy `Arvels Folly.esp` and the `Sound` folder into your `Data` folder. Then enable `Arvels Folly.esp`.

## Contents

- `Arvels Folly.esp`: the plugin
- `Sound/Voice/Skyrim.esm/MaleDarkElf/`: edited voice lines for Arvel
